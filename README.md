# 감사 시즌 2026

CPA 2차 회계감사 **답안 출력 연습** 게임. 브라우저에서 바로 돌아가고 설치·서버·인터넷이 필요 없다.

감사 시즌 하나를 수임 검토부터 감사보고서 발행까지 끌고 가는 시뮬레이션이다.
**모든 대응은 타이핑으로 한다.** 판단(해당한다 / 해당하지 않는다)도 문장 안에 써야 인정된다.

그리고 이 회사에는 **무언가가 숨어 있다.** 무엇이 얼마나 숨어 있는지는 시즌마다 다르다.
절차를 제대로 밟은 만큼만 드러나고, 놓친 것은 1년 뒤 감리에서 돌아온다.

```
수임 검토 → 위험평가 → 재고실사 입회 → 외부조회 → 회계추정치
   → 특수관계자 → 기타정보 → 후속사건 → 왜곡표시 평가 → 의견형성
                                                    → 1년 뒤 (감리)
```

## 시즌 시스템 — 선택이 쌓여서 엔딩이 된다

### 숨은 진실 (`data/truth.js`)

회사에는 실제 왜곡표시가 있다. 플레이어는 볼 수 없다.

| 진실 | 금액 | 존재 | 드러나는 조건 |
|---|---|---|---|
| ㈜한들상사 가공 매출채권 | 38억 | 매 시즌 | 특수관계자 장면에서 실증절차 |
| 순환 자금흐름으로 위장한 가공매출 | 23억 | 매 시즌 | 위험평가에서 **통제 무력화 + 분개 테스트**를 짚어 두고, 특수관계자 실증절차까지 |
| 외주 임가공 보관 재고 과대계상 | 34억 | 70% | 제3자 보관 재고에 대한 조회·검사 |
| 확정급여채무 과소계상 | 38억 | 65% | 한 방향 가정 변경 신호 + 경영진측 전문가 평가 |
| 4분기 매출 기간귀속 조작 | 8.4억 | 75% | 기간귀속 절차 확대 또는 조회 문제 건 대체절차 |
| 후속사건 대손충당금 미반영 | 23억 | 매 시즌 | ⓐ를 수정을 요하는 사건으로 분류 |

금액은 시즌마다 ±12% 흔들린다. **없는 시즌에 절차를 제대로 밟으면 "확인 완료 — 이상 없음"으로 기록된다.**
그것도 감사다. 절차를 안 밟았는데 마침 없었다면 엔딩에서 "운"으로 표시된다.

**핵심 함정:** 찾은 것만 왜곡표시 집계에 오른다. 아무것도 못 찾으면 집계가 작아 보이고,
그 사실에 근거한 적정의견은 형식상 **정답**이 된다. 그리고 1년 뒤 회사가 무너진다.

### 회사 태도

| | 오르내림 | 결과 |
|---|---|---|
| 회사를 압박하는 논점(`confront`)을 짚을 때 | 떨어진다 | 42 미만이면 경영진이 **조회 자체를 막는다**. 35 미만이면 자료 제출이 늦어져 **매 장면 감사시간이 더 든다** |
| 회사 입장을 받아주는 서술(`please`)을 쓸 때 | 오른다 | 50 이상이면 일반 조정사항은 **수정해 준다**. 대신 그런 서술은 오개념이라 파트너 신뢰가 깎이고, 놓친다 |

강하게 밀수록 진실에 가까워지지만 시간이 부족해진다. 온건하면 편하지만 놓친다. 정답이 하나가 아니다.

### 앞선 선택이 다음 장면을 바꾼다

| 장면 | 조건 | 나오는 판본 |
|---|---|---|
| 외부조회 | 회사 태도 42 미만 | **경영진의 조회 불허** — 재무담당임원이 직접 막아선다 |
| | 분개 전수추출 진행 중 | **위조 회신 포착** — 거래처 마스터를 대조하다 발신번호가 걸린다 |
| | 그 외 | 중요 금액 미회신 |
| 회계추정치 | 확정급여채무 조작이 있는 시즌 | 가정이 한 방향으로 변경 → **편의 있음**이 정답 |
| | 없는 시즌 | 가정이 시장 변화를 반영 → **편의 없음**이 정답. 같은 장면에서 판단이 뒤집힌다 |
| 특수관계자 | 위험평가에서 무력화를 올렸음 | 분개 전수추출로 **먼저 포착** |
| | 못 올렸음 | 외부 제보로 **뒤늦게** — 시간이 더 들고, 자금 순환 경로까지는 닿지 못한다 |
| 왜곡표시 평가 | 찾은 진실 · 회사 태도 | 집계표가 매번 다르다. 적대적이면 CFO 가 감사인 교체를 들먹인다 (압력 위협) |
| 의견형성 | 미수정 합계 · 전반성 · 감사증거 | **정답 의견이 매 시즌 다르다** — 적정·한정·부적정·의견거절 |

인물의 대사와 장면 앞 "여파" 문구도 앞선 선택에 따라 바뀐다.
여러 의견을 걸쳐 쓰면("한정의견 또는 부적정의견") 맞힌 것으로 치지 않는다. 감사의견은 하나다.

### 엔딩 — 세 축이 조립된다

| 감리 결과 | 회사의 운명 | 커리어 |
|---|---|---|
| 마감 실패 / 부적절한 의견 / 분식 발각 / 일부 미발견 지적 / 증거 부족 경고 / 무사통과 | 상장폐지 심사 / 재작성·관리종목 / 과징금 / 지배구조 개편 / 정상 | 유착 / 업무팀 제외 / 검사라는 평판 / 인차지 승진 / 무난 |

엔딩 화면에는 **이번 시즌의 진실**(무엇이 있었고, 무엇을 찾았고, 놓친 건 어떻게 찾았어야 했는지)과
**내가 내린 결정들**(장면별로 무엇이 바뀌었는지)이 나온다.

### 시즌 코드

같은 코드 = 같은 진실. 엔딩 화면의 **같은 시즌 다시 — 다른 선택으로** 를 누르면
진실은 그대로 두고 선택만 바꿔서 다시 해볼 수 있다.

### 조서

플레이 중 상단 **조서** 버튼. 지금까지 발견한 사항, 이상 없음을 확인한 것, 진행 중인 절차,
회사 태도, 장면별 기록이 쌓인다. 아직 찾지 못한 진실은 여기에도 나오지 않는다.

## 채점 엔진 (`js/engine.js`)

단순 문자열 포함 검사가 아니다.

| 단계 | 하는 일 | 예 |
|---|---|---|
| ① 정규화 | 공백·문장부호 제거 | `감사 증거를` → `감사증거` |
| ② 동의어 확장 | `data/lexicon.js` | `이기적 위협` = `자기이익위협` |
| ③ 오타 허용 | 한글 자모 편집거리 (5자 이상) | `거래명세써` → 인정 |
| ④ **부정문 무효화** | 같은 문장 안의 부정 표현이면 취소 | `대체절차를 수행할 필요가 없다` → 0점 |
| ⑤ 근접 조건 | 두 키워드가 같은 맥락에 있어야 | `범위제한` 과 `의견` 이 60자 이내 |

- **판단형 논점은 부정문을 허용한다**(`negOk`). `전반적이지 않다` 는 그 자체가 정답이다
- **부분문자열 오매칭 차단**(`notBefore`). `부적정의견` 안의 `적정의견` 을 잡지 않는다
- **판단이 틀리면 근거 서술은 0점** — 실제 GS 채점 방식
  > "예/아니오 판정이 틀려, 이유 서술의 정확성과 무관하게 부분점수를 부여하지 않았습니다"
- **키워드만 나열하면 구조점수 0 + 총점 75% 상한** — 실제 채점 코멘트 근거
  > "기준만 나열한 경우 일부 감점이 있을 수 있습니다"

```js
{

  art: 'meeting', area: '감사절차 수행과 결과 보고', standards: ['KSA 600'],

  line: '해외 종속기업 넷은 다른 법인이 감사했네. 우리가 뭘 해야 하지?',

  variants: [                                   // 선택. 위에서부터 조건이 맞는 첫 판본
    { id: 'HOSTILE', label: '자료 거부', when: function (S) { return S.rel.company < 35; }, body: '...' },
    { id: 'NORMAL',  label: '일반', body: '...' }  // 조건 없는 판본은 맨 아래 = 기본값
  ],
  enter: function (S, v) {                      // 선택. 앞선 선택에 따라 대사·여파 문구를 바꾼다
    if (S.flags.fraud_alert) return { note: '...', line: '...', speaker: 'cfo' };
  },
  situation: function (v, S) { return v.body; },
  exhibits:  function (v, S) { return [{ type: 'table', title: '...', head: [], rows: [] }]; },
  prompt: '감사인이 수행하여야 할 절차를 3줄 이내로 서술하시오.',
  timeLimit: 220, maxChars: 190, cost: 9,
  verdict: { yes: ['해당한다'], no: ['해당하지 않'], answer: 'yes', score: 14 },   // 선택
  rubric: {
    bonusCap: 12,
    must:  [{ kw: ['유의적 부문'], score: 14, label: '유의적 부문의 결정' }],
    bonus: [{ kw: ['부문감사인'], score: 6, label: '부문감사인의 적격성 평가' }],
    trap:  [{ kw: ['전적으로 의존'], score: -14, label: '부문감사인에게 책임 전가', please: true }]
  },
  confront: ['유의적 부문의 결정'],             // 짚으면 회사 태도가 떨어지는 논점 (label)
  flags: [{ if: ['유의적 부문의 결정'], set: 'group_ok', toast: '...' }],
  model: ['...'],
  ref: 'KSA 600'
}
```

새 진실을 이 장면에 걸고 싶으면 `data/truth.js` 에 `detect: { mode: 'all', need: ['s11#유의적 부문의 결정'] }` 을 추가한다.

### rubric 항목 옵션

| 필드 | 뜻 |
|---|---|
| `kw` | 인정할 표현들. 사전에 있으면 동의어가 자동 확장된다 |
| `score` | 배점 (`trap` 은 음수) |
| `label` | 결과 화면의 논점 이름. **`flags` · `confront` · 진실의 `detect` 가 이 이름을 참조한다** |
| `hint` | 틀렸을 때 보여줄 힌트 |
| `negOk: true` | 부정문 허용 — 판단형 논점에 반드시 |
| `notBefore: ['부']` | 부분문자열 오매칭 차단 |
| `near`, `within` | 다른 키워드와 같은 맥락에 있어야 인정 |
| `please: true` | (trap 전용) 회사 입장을 받아주는 서술 — 회사 태도가 오른다 |

## 검증 (`node tools/validate.js`)

장면을 추가·수정한 뒤에는 반드시 돌린다.

1. **구조** — `flags` · `confront` · 진실의 `detect`/`verify` 가 실제로 존재하는 논점 라벨을 가리키는가
2. **모범답안 자가채점** — 80점 미만이면 채점기준 결함. 집계·의견 장면은 시뮬레이션 중 생성된 모범답안까지 검사한다
3. **판별력** — 정답 / 오답 / 나열 / 판단 반대 / 조건 오독
4. **경우의 수** — 성향이 다른 플레이어를 시즌 60개씩 돌린다. 게임 화면과 같은 `season.js` 를 쓴다

측정 결과 (성향 7종 × 시즌 60개):

| 성향 | 플레이 방식 | 주로 나오는 감리 결과 |
|---|---|---|
| 강경 | 모든 논점을 짚는다 | 무사통과 60/60 |
| 온건 | 압박 논점을 피하고 회사 입장을 받아준다 | 일부 미발견 55 · 분식 발각 5 |
| 혼합 | 압박 논점은 반반 | 일부 미발견 40 · 무사통과 19 |
| 대충 | 논점의 40%만 | 부적절한 의견 35 · 분식 발각 20 |
| **눈뜬 장님** | 무난하게 쓰지만 파고들지 않는다 | **분식 발각 60/60** — 찾은 사실에 비추어 적정의견은 "정답"이었다 |
