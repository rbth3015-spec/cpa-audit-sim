# 회계감사 시뮬레이터

CPA 2차 회계감사 **답안 출력 연습**용 웹 앱. 브라우저에서 바로 실행되고, 서버·설치·인터넷이 필요 없다.

실제 2차 출제 형식을 따른다.

```
문제 N (배점)  →  물음 1, 2, 3 ...   ※ 각 물음은 독립적
```

---

## 실행

`index.html` 을 브라우저로 열면 끝이다.

> 로컬 파일에서도 돌아가도록 데이터를 `.json` 이 아니라 `.js` 로 두고 일반 `<script src>` 로 불러온다.
> `file://` 에서는 `fetch()` 와 ES 모듈이 CORS 로 차단되기 때문이다.

수정하면서 볼 때는 정적 서버를 띄우는 편이 편하다.

```bash
python -m http.server 8765
```

## 채점 엔진

`js/engine.js`. 단순 문자열 포함 검사가 아니다. 5단계를 통과해야 득점한다.

| 단계 | 하는 일 | 예 |
|---|---|---|
| ① 정규화 | 공백·문장부호 제거, 소문자화 | `감사 증거를` → `감사증거` |
| ② 동의어 확장 | `data/lexicon.js` 참조 | `이기적 위협` = `자기이익위협` = `self-interest` |
| ③ 오타 허용 | 한글 자모 편집거리 (5자 이상 키워드만) | `거래명세써` → 인정 |
| ④ **부정문 무효화** | 키워드 뒤 부정 표현이면 득점 취소 | `대체절차를 수행할 필요가 없다` → 0점 |
| ⑤ 근접 조건 | 두 키워드가 같은 맥락에 있어야 인정 | `범위제한` 과 `의견` 이 60자 이내 |

부정문 탐지는 **같은 문장 안에서만** 한다. 문장 경계에 표지(`ᚠ`)를 남겨 두기 때문에
`…지배기구와 커뮤니케이션한다. 거부가 타당하지 않다면…` 을 부정으로 오판하지 않는다.

**판단형 논점은 부정문을 허용한다**(`negOk: true`). `전반적이지 않다` / `중요하지 않다` 는
그 자체가 정답 서술이기 때문이다.

**부분문자열 오매칭 차단**(`notBefore`). `부적정의견` 안의 `적정의견` 을 잡지 않는다.

### 꼼수 방지

키워드만 나열하면 **구조점수 0점 + 총점 75% 상한**이 걸린다.

| 형식 | 구조점수 |
|---|---|
| `essay` | 15점 — 문장 구성 6 / 인과·논리 연결 4 / 판단·결론 명시 5 |
| `judge` | 10점 — 근거 문형(`~때문이다`) 6 / 기준·법령 근거 제시 4 |
| `list` | 없음 (나열이 곧 정답) |

O·X 판단이 틀리면 근거 서술은 **30%만** 인정된다.

## 다양성 — 같은 문제를 두 번 풀어도 답이 다르다

콘텐츠 개수가 아니라 **구조**로 확보한다.

- **variant** — 같은 문제의 숫자·조건만 바꾼 판본. **조건이 바뀌면 정답이 뒤집힌다**
- **pool + pick** — `judge` 상황 풀에서 매번 다른 조합을 뽑는다
- **꼬리질문 분기** — 답변 점수에 따라 추가 질문이 갈린다
- **오답 우선 재출제** — 과거 70점 미만 물음에 3배 가중치

variant 예 (문제 4 · 외부조회 미회신):

| variant | 조건 | 정답 방향 |
|---|---|---|
| A | 미회신 3건, 42억(18%) | 대체절차 → 증거 부족 시 **범위제한** |
| B | 미회신 1건, 1.8억(0.8%), 기말 후 전액 회수 | 대체절차로 **충분, 종결** |
| C | 3건 + **경영진이 조회 자체를 불허** | 정당성 평가 → **지배기구 커뮤니케이션** → 범위제한 |

A 식으로 답하면 B 에서는 감점된다. 암기가 통하지 않는다.

## 문제 추가하기

`data/cases.js` 배열에 객체 하나를 붙이면 된다.

```js
{
  id: 'p07', no: 7, points: 14, stage: 7,
  title: '그룹재무제표에 대한 감사',
  chapter: '6편 2장 · 그룹재무제표에 대한 감사절차와 보고',
  standards: ['KSA 600'],
  intro: '다음은 ㈜태성의 연결재무제표 감사에 관한 물음이다.',
  questions: [{
    no: 1, form: 'essay', timeLimit: 200,
    text: '감사인이 수행하여야 할 절차를 3줄 이내로 서술하시오.',
    variants: [{ id: 'A', label: '유의적 부문' }],
    situation: function (v) { return '...'; },
    exhibits: function (v) { return [{ type: 'table', title: '...', head: [], rows: [] }]; },
    parts: function (v) {
      return [{ maxChars: 190, rubric: {
        bonusCap: 12,
        must:  [{ kw: ['유의적 부문'], score: 14, label: '유의적 부문의 결정' }],
        bonus: [{ kw: ['부문감사인'], score: 6, label: '부문감사인의 적격성 평가' }],
        trap:  [{ kw: ['부문감사인에게 전적으로 의존'], score: -14, label: '책임 전가' }]
      }}];
    },
    model: function (v) { return ['...']; },
    ref: 'KSA 600'
  }]
}
```

### rubric 항목 옵션

| 필드 | 뜻 |
|---|---|
| `kw` | 인정할 표현들. 사전에 있으면 동의어가 자동 확장된다 |
| `score` | 배점 (`trap` 은 음수) |
| `label` | 결과 화면에 표시될 논점 이름 |
| `hint` | 틀렸을 때 보여줄 힌트 |
| `negOk: true` | 부정문을 허용 — **판단형 논점에 반드시** |
| `notBefore: ['부']` | 부분문자열 오매칭 차단 |
| `near`, `within` | 다른 키워드와 같은 맥락에 있어야 인정 |

`judge` 형식은 `parts` 대신 `pool` 과 `variants[].pick` 을 쓴다.

## 동의어 사전

`data/lexicon.js`. **정답인데 0점이 나오는 걸 막는 핵심 파일이다.**

교재 표기를 대표어로 둔다. 기준서 원문과 갈리는 지점이 있다.

| 교재 | 기준서·통용 |
|---|---|
| 이기적 위협 | 자기이익위협 |
| 압력 위협 | 협박위협 |

교재 축약도 인정한다 — `성시범`(성격·시기·범위), `거계공`(거래유형·계정잔액·공시), `명사`(명백히 사소한 금액), `Com.`(커뮤니케이션), `충적증거`.

**본인이 쓰는 두문자는 여기에 계속 추가할 것.** 사전에 없으면 정답을 써도 0점이 나온다.

```js
'부정의 삼각형': ['부정삼각형', 'fraud triangle', '유기합'],  // ← 본인 암기법 추가
```

## 첨삭 요청

채점 결과 화면의 **첨삭 요청 복사** 버튼을 누르면
상황 · 문항 · 내 답안 · 자동채점 내역 · 모범답안이 한 덩어리로 복사된다.
그대로 Claude 에 붙여넣으면 정성 첨삭을 받을 수 있다.

자동채점은 키워드 기반이라 **오채점이 있을 수 있다.**
정답인데 누락으로 잡힌 표현이 나오면 `data/lexicon.js` 에 추가하면 된다.

## 검증

`node` 로 돌리는 검증 스크립트가 있다. 문제를 추가한 뒤에는 반드시 돌려볼 것.

- 모든 문제 · 모든 variant 의 구조 검증 (필드 누락, rubric 누락, `ox` 누락, 예외)
- **모범답안 자가채점** — 모범답안이 80점 미만이면 채점기준에 결함이 있다는 뜻이다
- 판별력 시나리오 (정답 / 오답 / 나열 꼼수 / 조건 오독 / 오타)
