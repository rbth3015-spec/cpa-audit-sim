# 감사 시즌 2026

CPA 2차 회계감사 **답안 출력 연습** 게임. 브라우저에서 바로 돌아가고 설치·서버·인터넷이 필요 없다.

감사 시즌 하나를 수임 검토부터 감사보고서 발행까지 끌고 가는 시뮬레이션이다.
**모든 대응은 타이핑으로 한다.** 판단(해당한다 / 해당하지 않는다)도 문장 안에 써야 인정된다.

이 회사에는 **무언가가 숨어 있다.** 무엇이 얼마나 숨어 있는지는 시즌마다 다르다.
절차를 제대로 밟은 만큼만 드러나고, 놓친 것은 1년 뒤 감리에서 돌아온다.

```
수임 검토 → 위험평가 → 재고실사 입회 → 외부조회 → 회계추정치
   → 특수관계자 → 기타정보 → 후속사건 → 왜곡표시 평가 → 의견형성
                                                    → 1년 뒤 (감리)
```

## 좌석 — 같은 감사, 다른 자리

시즌을 시작할 때 자리를 고른다. 장면과 숨은 진실은 같지만 **누가 나에게 무엇을 묻는지**가 달라진다.
같은 논점을 세 각도에서 보게 되니 출력 연습과 함께 이해가 따라온다.

| 좌석 | 하는 일 | 칸마다 묻는 사람 | 체감 |
|---|---|---|---|
| **어쏘** | 현장에서 절차를 직접 수행하고 보고 | 시니어 유가온이 지시하고 묻는다 | 시간 넉넉, 회사와 부딪칠 일 적음 |
| **시니어** | 팀을 배분하고 판단을 취합해 위에 올림 | 어쏘 한결이 보고하고, 내가 판단한다 (결론은 파트너가 직접 묻는다) | 균형 |
| **업무수행이사** | 결론을 내고 회사와 지배기구를 상대 | 유가온이 "이사님" 하고 보고를 올린다 | 시간 빠듯, 회사 태도가 크게 흔들림 |

같은 방식(모든 논점을 강하게 짚기)으로 플레이해도 결과가 다르다 — 실측:

| 같은 플레이 | 남은 시간 | 회사 태도 | 외부조회에서 만나는 상황 |
|---|---|---|---|
| 어쏘 | 32 | 29 | 위조 회신을 알아챈다 |
| 시니어 | 17 | 6 | 경영진이 조회 자체를 막는다 |
| 업무수행이사 | **5** | **2** | 경영진이 조회 자체를 막는다 |

엔딩에서 **같은 시즌을 다른 좌석으로** 바로 다시 해볼 수 있다.

## 한 장면 = 짧은 칸 2~3개

한 문장에 논점을 여러 개 욱여넣게 하지 않는다. 실제 시험도 "각각 1줄 이내"로 쪼개서 묻는다.

```
[유가온] 자네가 창고 나갈 거야. 어디를 언제 볼 건지 말해봐.
① 입회할 장소와 시기                                         110자
   ▸ 답하기 → 바로 채점 → "좋아, 그거야."
[박정후] 임가공 물량은 거래처가 관리합니다. 명세서로 갈음하시죠?
③ 제3자가 보관하는 재고 74억원에 대한 대응
   ▸ 답하기 → 바로 채점 → "…그렇게까지 하셔야 합니까."
```

- 칸마다 **따로 묻고, 따로 채점하고, 묻던 사람이 바로 반응한다**
- 재무담당임원은 점수가 아니라 **압박했는가 · 편들었는가**에 반응한다
- 칸 결과에 **"이 칸은 「제3자 보관 재고는 제3자에 대한 조회 또는 검사」를 중심으로 채점했습니다"** 가 붙는다 (GS 강평 방식)
- 장면이 끝나면 게이지 변화, 발견 사항, 분기 알림, 모범답안이 정산된다

## 채점 방식

### 부분점수

핵심어는 있으나 한정어가 빠지면 **절반**. 실제 GS 채점의 "문장 완성도에 따라 차등 부여"를 옮겼다.

| 답안 | 결과 |
|---|---|
| 실사 과정을 관찰하고 **시험적 검사**를 수행한다 | 만점 |
| 실사 과정을 관찰하고 재고를 **검사**한다 | 절반 (◐) |

부분점수는 점수에만 반영된다. 분기와 진실 발견은 **만점으로 짚었을 때만** 인정한다.

### 짧은 답 전용 구조 채점

긴 문장을 강요하지 않는다. **서술어로 끝맺었는지**만 본다. 명사만 늘어놓으면 나열로 보고 75% 상한.

### 가점은 분모에 넣지 않는다

필수 논점을 다 쓰면 100점. 가점은 놓친 부분을 메워주는 역할만 한다.

### 그 밖의 엔진 규칙

| 단계 | 하는 일 | 예 |
|---|---|---|
| ① 정규화 | 공백·문장부호 제거 | `감사 증거를` → `감사증거` |
| ② 동의어 확장 | `data/lexicon.js` | `이기적 위협` = `자기이익위협` |
| ③ 오타 허용 | 한글 자모 편집거리 (5자 이상) | `거래명세써` → 인정 |
| ④ **부정문 무효화** | 같은 문장 안의 부정 표현이면 취소 | `대체절차를 수행할 필요가 없다` → 0점 |
| ⑤ 근접 조건 | 두 키워드가 같은 맥락에 있어야 | `범위제한` 과 `의견` 이 60자 이내 |

- **판단형 논점은 부정문을 허용**(`negOk`) — `전반적이지 않다` 는 그 자체가 정답
- **부정어가 옆 절로 번지지 않게**(`negWindow`) — `ⓑ는 …불일치이며, ⓒ는 기준이 없으므로` 의 "없"은 ⓑ 가 아니라 ⓒ 의 것
- **부분문자열 오매칭 차단**(`notBefore`) — `부적정의견` 안의 `적정의견`
- **판단 추출** — "훼손위협이 발생" 뒤에 "하지 않는다"가 붙으면 반대 판단으로 읽는다
- **판단이 틀리면 근거 서술은 0점** — 실제 GS 채점 방식
- **여러 의견을 걸쳐 쓰면 오답** — "한정의견 또는 부적정의견"은 맞힌 것이 아니다

### 판별력 (실측, 칸 단위)

| 답안 | 점수 |
|---|---|
| 정답 | 100 |
| 핵심어는 있으나 한정어 누락 | 57 |
| 키워드 나열 | 76 (상한) |
| 회사 명세서 수용 (오개념) | 0 |
| 판단 반대 | 0 |

## 이해를 돕는 장치 — 설명이 아니라 되짚기

- **「왜?」** — 칸 결과의 논점 옆 버튼. 궁금할 때만 펼치는 2~3문장 해설
- **개념 카드** — 제대로 짚은 논점은 **익힌 카드**, 놓친 논점은 **복습 카드**로 조서에 쌓인다. 나중에 짚으면 복습 카드가 익힌 카드로 넘어간다 (38장)
- **이번 시즌의 진실** — 엔딩에서 무엇이 있었고, 무엇을 찾았고, 놓친 것은 어떻게 찾았어야 했는지

## 시즌 시스템 — 선택이 쌓여서 엔딩이 된다

### 숨은 진실 (`data/truth.js`)

| 진실 | 금액 | 존재 | 드러나는 조건 |
|---|---|---|---|
| ㈜한들상사 가공 매출채권 | 38억 | 매 시즌 | 특수관계자 장면에서 실증절차 |
| 순환 자금흐름으로 위장한 가공매출 | 23억 | 매 시즌 | 위험평가에서 **통제 무력화 + 분개 테스트**를 짚어 두고, 특수관계자 실증절차까지 |
| 외주 임가공 보관 재고 과대계상 | 34억 | 70% | 제3자 보관 재고에 대한 조회·검사 |
| 확정급여채무 과소계상 | 38억 | 65% | 한 방향 가정 변경 신호 + 경영진측 전문가 평가 |
| 4분기 매출 기간귀속 조작 | 8.4억 | 75% | 기간귀속 절차 확대 또는 조회 문제 건 대체절차 |
| 후속사건 대손충당금 미반영 | 23억 | 매 시즌 | ⓐ를 수정을 요하는 사건으로 분류 |

찾은 것만 왜곡표시 집계에 오른다. 아무것도 못 찾으면 집계가 작아 보이고,
그 사실에 근거한 적정의견은 형식상 **정답**이 된다. 그리고 1년 뒤 회사가 무너진다.

### 회사 태도

압박하는 논점을 짚을수록 떨어진다 → 42 미만이면 조회를 막고, 35 미만이면 자료가 늦어져 시간이 더 든다.
회사 입장을 받아주면 오른다 → 일반 조정사항은 고쳐주지만 놓친다. 정답이 하나가 아니다.

### 앞선 선택이 다음 장면을 바꾼다

| 장면 | 조건 | 판본 |
|---|---|---|
| 외부조회 | 회사 태도 42 미만 / 분개 전수추출 진행 / 그 외 | 조회 불허 / 위조 회신 포착 / 미회신 |
| 회계추정치 | 퇴직급여 조작이 있는 시즌 / 없는 시즌 | 편의 있음 / **편의 없음** (판단이 뒤집힌다) |
| 특수관계자 | 위험평가에서 무력화를 올림 / 못 올림 | 먼저 포착 / 제보로 뒤늦게 |
| 왜곡표시 | 찾은 진실 · 회사 태도 | 집계표가 매번 다르다 |
| 의견형성 | 미수정 합계 · 전반성 · 증거 | **정답 의견이 매 시즌 다르다** |

### 엔딩 — 세 축이 조립된다

감리 결과(6) × 회사의 운명(5) × 커리어(5). 시즌 코드가 같으면 진실도 같다.

## 칸 추가하기

```js
parts: function (v, S) {
  return [
    { who: 'cfo',                                   // 생략하면 좌석에 따라 정해진다
      say: { staff: '…', senior: '…', partner: '…' }, // 좌석별 대사 (문자열 하나도 가능)
      ask: '제3자가 보관하는 재고에 대한 대응',
      maxChars: 110, timeLimit: 100,
      verdict: { yes: ['해당한다'], no: ['해당하지 않'], answer: 'yes', score: 14 },  // 선택
      rubric: {
        bonusCap: 6,
        must: [{
          kw: ['제3자 조회', '직접 검사'], score: 18,
          half: ['조회', '검사'],                    // 핵심어만 있으면 절반
          label: '제3자 보관 재고는 제3자에 대한 조회 또는 검사',
          why: '…'                                   // 개념 카드로 쌓이는 해설
        }],
        bonus: [],
        trap: [{ kw: ['명세서로 갈음'], score: -16, label: '…', please: true }]
      },
      model: '한두 문장 모범답안' }
  ];
}
```

좌석별 말투 기준 — `staff` 는 시니어가 어쏘에게(반말), `senior` 는 어쏘가 시니어에게(존댓말), `partner` 는 시니어가 이사에게("이사님").

| rubric 필드 | 뜻 |
|---|---|
| `kw` · `score` · `label` | 인정 표현 · 배점 · 논점 이름. **`label` 은 분기 · 회사 태도 · 진실 발견의 계약이다** |
| `half` | 핵심어만 있을 때 절반 인정 |
| `why` | 개념 카드 해설 |
| `negOk` | 부정문 허용 — 판단형 논점에 반드시 |
| `negWindow` | 부정어를 찾는 범위(글자 수). 옆 절의 부정어가 번질 때 줄인다 |
| `notBefore` | 부분문자열 오매칭 차단 |
| `near` · `within` | 다른 키워드와 같은 맥락에 있어야 인정 |
| `please` | (trap) 회사 입장을 받아주는 서술 — 회사 태도가 오른다 |

## 검증 (`node tools/validate.js`)

1. **구조** — 모든 좌석 × 판본에서 칸 · 화자 · 라벨이 이어지는가. 파트너 자리에서 파트너가 말하지 않는가
2. **모범답안 자가채점** — 칸마다 80점 미만이면 채점기준 결함. 의견형성처럼 상태에 따라 생성되는 칸까지 검사
3. **판별력** — 정답 / 부분점수 / 나열 / 오개념 / 판단 반대
4. **경우의 수** — 성향 8종 × 좌석 3 × 시즌 25개

측정 결과: 칸 42개(판본 포함) · 개념 카드 38장 · **엔딩 조합 36가지** · 모든 판본 · 엔딩 · 정답 의견 도달

| 성향 | 플레이 방식 | 주로 나오는 감리 결과 |
|---|---|---|
| 강경 | 모든 논점을 짚는다 | 무사통과 75/75 |
| 온건 | 압박 논점을 피하고 회사 입장을 받아준다 | 일부 미발견 60 · 분식 발각 15 |
| 혼합 | 압박 논점은 반반 | 일부 미발견 48 · 무사통과 22 |
| 대충 | 논점의 40%만 | 부적절한 의견 46 · 분식 발각 26 |
