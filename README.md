# 감사 시즌 2026

CPA 2차 회계감사 **답안 출력 연습** 게임. 브라우저에서 바로 돌아가고 설치·서버·인터넷이 필요 없다.

기출 문제를 그대로 옮긴 문제집이 아니다. 감사 시즌 하나를 처음부터 끝까지 끌고 가는 시뮬레이션이고,
**모든 대응은 타이핑으로 한다.** 무엇을 짚느냐에 따라 뒤 장면이 바뀌고, 1년 뒤 감리 결과로 엔딩이 갈린다.

```
수임 검토 → 위험평가 → 재고실사 입회 → 외부조회 → 회계추정치
   → 특수관계자 → 기타정보 → 후속사건 → 왜곡표시 평가 → 의견형성
                                                    → 에필로그(감리)
```

## 실행

`index.html` 을 브라우저로 열면 끝이다.

> 데이터를 `.json` 이 아니라 `.js` 로 두고 일반 `<script src>` 로 불러온다.
> `file://` 에서는 `fetch()` 와 ES 모듈이 CORS 로 차단되기 때문이다.

고치면서 볼 때는 정적 서버가 편하다.

```bash
python -m http.server 8765
```

## 게임 장치

### 게이지 3종

| | 오르내리는 조건 | 결과 |
|---|---|---|
| **감사증거** | 답안 점수만큼 쌓인다 | 55 미만으로 마지막에 도달하면 **범위제한**이 강제된다 |
| **감사시간** | 장면마다 줄고, 답안이 길수록 더 준다 | 0이 되면 **마감 실패** 엔딩 |
| **신뢰** | 오개념을 쓰면 급락 | 높아야 최고 엔딩 |

### 분기 — 내 답안이 미래를 바꾼다

```
위험평가에서 "경영진의 내부통제 무력화" + "분개 테스트" 를 짚으면
  → 특수관계자 장면에서 분개 전수추출로 미공시 거래를 먼저 포착한다
  → 못 짚으면 외부 제보로 뒤늦게 알게 되고,
     왜곡표시 집계에 18.6억이 추가로 붙는다

재고실사에서 "보관장소" + "실사 시기" 를 둘 다 짚으면
  → 물류센터 입회 일정이 확보된다
  → 못 짚으면 제3자 보관분 9.2억이 왜곡표시로 얹힌다
```

그 결과 **마지막 장면의 정답 의견 자체가 회차마다 달라진다.**
미수정왜곡표시 합계와 감사증거 게이지를 보고 적정·한정·부적정·의견거절 중 무엇인지 스스로 판단해야 한다.

## 채점 엔진

`js/engine.js`. 단순 문자열 포함 검사가 아니다. 5단계를 통과해야 득점한다.

| 단계 | 하는 일 | 예 |
|---|---|---|
| ① 정규화 | 공백·문장부호 제거, 소문자화 | `감사 증거를` → `감사증거` |
| ② 동의어 확장 | `data/lexicon.js` 참조 | `이기적 위협` = `자기이익위협` = `self-interest` |
| ③ 오타 허용 | 한글 자모 편집거리 (5자 이상 키워드만) | `거래명세써` → 인정 |
| ④ **부정문 무효화** | 키워드 뒤 부정 표현이면 득점 취소 | `대체절차를 수행할 필요가 없다` → 0점 |
| ⑤ 근접 조건 | 두 키워드가 같은 맥락에 있어야 인정 | `범위제한` 과 `의견` 이 60자 이내 |

부정문 탐지는 **같은 문장 안에서만** 한다. 문장 경계에 표지(`ᚠ`)를 남겨 두기 때문에
`…지배기구와 커뮤니케이션한다. 거부가 타당하지 않다면…` 을 부정으로 오판하지 않는다.

**판단형 논점은 부정문을 허용한다**(`negOk: true`). `전반적이지 않다` / `중요하지 않다` 는 그 자체가 정답이다.

**부분문자열 오매칭 차단**(`notBefore`). `부적정의견` 안의 `적정의견` 을 잡지 않는다.

### O·X 버튼이 없는 이유

출력 연습이 목적이므로 판단도 타이핑해야 한다.
`해당한다 / 해당하지 않는다` 를 **문장 안에** 쓰면 엔진이 판단 방향을 읽어낸다(`readVerdict`).
양쪽 표현이 다 나오면 더 구체적인(긴) 쪽을, 길이가 같으면 뒤에 온 쪽을 결론으로 본다.

**판단이 틀리면 근거 서술은 0점이다.** 실제 GS 채점이 그렇게 한다 —
> "예/아니오 판정이 틀려, 이유 서술의 정확성과 무관하게 부분점수를 부여하지 않았습니다"

### 키워드 나열 차단

키워드만 늘어놓으면 **구조점수 0점 + 총점 75% 상한**. 이것도 실제 채점 코멘트에 근거한다 —
> "고유위험요소(주,불,복,변,기)를 사례에 직접 대입하여 판단근거를 제시해야 하며, **기준만 나열한 경우 일부 감점**이 있을 수 있습니다"

| 형식 | 구조점수 |
|---|---|
| `essay` | 15점 — 문장 구성 6 / 인과·논리 연결 4 / 판단·결론 명시 5 |
| `judge` | 10점 — 근거 문형(`~때문이다`) 6 / 기준·법령 근거 제시 4 |
| `list` | 없음 (나열이 곧 정답) |

## 장면 추가하기

`data/scenes.js` 배열에 객체 하나를 붙이면 된다.

```js
{
  id: 's11', day: '20×7. 3. 20.', chapter: '그룹감사',
  art: 'meeting', area: '감사절차 수행과 결과 보고', standards: ['KSA 600'],
  speaker: 'partner',
  line: '해외 종속기업 넷은 다른 법인이 감사했네. 우리가 뭘 해야 하지?',
  situation: '...',
  exhibits: [{ type: 'table', title: '...', head: [], rows: [] }],
  prompt: '감사인이 수행하여야 할 절차를 3줄 이내로 서술하시오.',
  timeLimit: 220, maxChars: 190, cost: 9,
  verdict: { yes: ['해당한다'], no: ['해당하지 않'], answer: 'yes', score: 14 },  // 선택
  rubric: {
    bonusCap: 12,
    must:  [{ kw: ['유의적 부문'], score: 14, label: '유의적 부문의 결정' }],
    bonus: [{ kw: ['부문감사인'], score: 6, label: '부문감사인의 적격성 평가' }],
    trap:  [{ kw: ['전적으로 의존'], score: -14, label: '부문감사인에게 책임 전가' }]
  },
  flags: [{ if: ['유의적 부문의 결정'], set: 'group_ok', toast: '...' }],  // 선택
  model: ['...'],
  ref: 'KSA 600'
}
```

### rubric 항목 옵션

| 필드 | 뜻 |
|---|---|
| `kw` | 인정할 표현들. 사전에 있으면 동의어가 자동 확장된다 |
| `score` | 배점 (`trap` 은 음수) |
| `label` | 결과 화면에 표시될 논점 이름. **`flags.if` 가 이 이름을 참조한다** |
| `hint` | 틀렸을 때 보여줄 힌트 |
| `negOk: true` | 부정문 허용 — **판단형 논점에 반드시** |
| `notBefore: ['부']` | 부분문자열 오매칭 차단 |
| `near`, `within` | 다른 키워드와 같은 맥락에 있어야 인정 |

`situation` · `exhibits` · `rubric` · `model` 은 함수로 써서 `variants` 별로 다르게 만들 수 있다.

## 동의어 사전

`data/lexicon.js`. **정답인데 0점이 나오는 걸 막는 핵심 파일이다.**

실제 답안지와 강사 두문자를 읽고 맞췄다.

| 본인·강사 표기 | 표준 표기 |
|---|---|
| 압력위험 | 압력 위협 |
| 고유위험 요인 | 고유위험요소 |
| 주,불,복,변,기 | 주관성·불확실성·복잡성·변화·기타부정위험요소 |
| 부정의 동기 | 유인 또는 압력 |
| MA수준 | 경영진주장 수준 |

교재 축약도 인정한다 — `성시범`, `거계공`, `명사`, `Com.`, `충적증거`.

**새로 쓰는 표기가 생기면 여기에 계속 추가할 것.** 사전에 없으면 정답을 써도 0점이다.

## 검증

장면을 추가·수정한 뒤에는 반드시 돌린다.

```bash
node tools/validate.js
```

- 전 장면·전 variant 구조 검증 (필드 누락, rubric 누락, **`flags` 가 없는 라벨을 참조하는지**)
- **모범답안 자가채점** — 80점 미만이면 채점기준에 결함이 있다는 뜻이다.
  모범답안대로 썼는데 깎인다면, 실제로 그 답을 쓴 사람도 억울하게 깎인다
- 판별력 시나리오 (정답 / 오답 / 나열 꼼수 / 판단 반대 / 조건 오독)
