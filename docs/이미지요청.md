# 원판 요청서 — 복붙용

나노바나나(또는 다른 생성 모델)에 **코드블록 하나를 그대로 복사해서 붙이면** 된다.
조립할 것 없이 한 블록이 이미지 한 장이다.

## 쓰는 법

1. 아래 코드블록을 그대로 복사 → 붙여넣기 → 생성
2. **파일 이름을 표대로 맞춰서** 저장 (`tools/plates.js` 가 이름만 보고 규격을 고른다)
3. 파일을 그냥 보내면 된다. 비율이 좀 달라도 잘라 준다

```bash
node tools/plates.js ~/받은폴더        # → assets/art/ 에 규격대로
node tools/plates.js ~/받은폴더 --zoom=0.7 --anchor=0.25   # 더 당기고 싶으면
```

> **대화창에 붙여넣은 이미지는 디스크에 파일로 떨어지지 않는다.** 경로가 없어서
> `plates.js` 를 못 돌린다. **파일로 첨부**해 달라 (드래그해서 올리는 방식).

## 순서

| 순위 | 무엇 | 왜 |
|---|---|---|
| **1** | 초상 4장 | 지금 원 하나 + 사각형 하나라 네 사람이 구별되지 않는다. 제일 크게 이긴다 |
| 2 | 무대 8장 | 지금 SVG 도 읽히긴 한다. 사진이 들어오면 확실히 낫다 |
| 3 | 히어로 · 타이틀 2장 | 마지막 |
| 선택 | 동영상 | 타이틀 한 자리만. 아래 D 절 |

> 초상 4장은 **첫 장을 참조 이미지로 물려서** 나머지를 뽑는 게 좋다.
> 같은 렌즈 · 같은 조명 · 같은 사무실에서 찍은 것처럼 맞춰진다.

### 초상은 당겨서 쓴다

화면에서 **136×136** 으로 줄어든다. 여백이 많으면 얼굴이 작아져 누가 누군지 안 보인다.
그래서 `plates.js` 가 초상을 원본의 76% 만 당겨 쓴다 (`--zoom` 으로 조절).
뽑을 때부터 조금 타이트하게 잡아 주면 더 좋다 — **어깨선까지, 머리 위 여백은 조금만.**

생성기 워터마크가 모서리에 찍혀 있으면 이 크롭에서 대개 같이 빠진다.
빠지지 않으면 `--zoom` 을 더 낮춰서 맞춘다.

# D. 동영상 (선택)

## 코덱을 먼저 맞춰야 한다

검증용 Chromium 에 **H.264 가 없다.** 확인한 결과:

| 코덱 | 여기서 |
|---|---|
| MP4 / H.264 | ✕ **못 연다** |
| WebM / VP9 · VP8 · AV1 | ○ |
| MP4 / AV1 | ○ |

즉 MP4(H.264)로 주면 **당신 브라우저에서는 잘 돌아가지만 내가 열어서 확인할 수
없다.** 포스터 프레임도 못 뽑는다. 그래서 둘 중 하나로:

- **WebM(VP9) 로 주면** — 내가 열어서 검증하고 포스터 프레임까지 뽑는다 (권장)
- **MP4 로만 준다면** — 정지 이미지 한 장을 같이 보내 달라. 그게 포스터이자
  `prefers-reduced-motion` 대체 화면이 된다

## 어디에 넣을지 — 타이틀 하나만 권한다

| 자리 | 동영상 | 왜 |
|---|---|---|
| **타이틀 아트 패널** | ○ 권함 | 크고, 정지해 있고, 읽는 동안 계속 보인다. 움직임이 값을 한다 |
| 엔딩 히어로 | △ 가능 | 마지막 한 번의 장면. 넣으면 좋지만 급하지 않다 |
| 무대 8장 | ✕ 권하지 않음 | 글자 밑에서 움직이면 읽기를 방해한다. 2분마다 장면이 바뀌니 분위기가 아니라 소음이 된다. 8개 × 1MB 면 "한 폴더로 도는 앱"이 무거워진다 |

**어느 쪽이든 정지 이미지는 여전히 필요하다.** `prefers-reduced-motion: reduce`
에서 연출을 전부 끄는 것이 이 디자인 시스템의 규칙이고, 동영상도 예외가 아니다.

## 영상 규격

- **5~8초 · 소리 없음 · 무한 루프.** 첫 프레임과 끝 프레임이 이어져야 한다
- **카메라를 거의 움직이지 않는다.** 아주 느린 push-in 정도. 팬 · 컷 · 줌 금지
- 움직이는 것은 **빛뿐**이어야 한다 (창문이 하나씩 켜지고 꺼지는 정도)
- 나머지 제약은 사진과 같다 — 글자 · 로고 · 숫자 · 빨강 없음, 무채색

## 받으면 내가 하는 것

1. `<video muted loop playsinline autoplay poster="…">` 로 `.as-art` 안에 넣는다
2. `prefers-reduced-motion: reduce` 면 **재생하지 않고 포스터만** 보여준다
3. WebM 이면 포스터 프레임을 canvas 로 직접 뽑는다 (파일을 따로 안 받아도 된다)
4. 파일이 없는 자리는 그대로 SVG 로 둔다 — **한 자리만 영상이어도 앱은 돈다**

# 공통 — 원판에 넣지 말 것

| 넣지 않는다 | 이유 |
|---|---|
| 글자 · 숫자 · 로고 · 간판 | 태그 · 캡션 · 기준일 도장이 전부 HTML 로 위에 올라간다. 두 번 겹친다 |
| **빨강** | `--as-red` 는 주 액션과 마킹 전용이다. 사진에 빨강이 있으면 그 규칙이 깨진다 |
| 워터마크 · 프레임 · 비네팅 | 어두운 그라디언트를 CSS 가 따로 건다 |
| 웃는 얼굴 · 악수 · 유리 빌딩 클리셰 | 스톡 티가 난다. 이 게임은 야근하는 회계법인이다 |

**무채색으로.** 코드에서 `grayscale(1) contrast(1.1~1.16)` 가 한 번 더 걸린다.
원판부터 무채색이어야 여러 장 사이 톤이 안 튄다 (컬러로 나와도 `plates.js` 가 굽긴 한다).

**노출은 중간~밝게.** 위에 어두운 그라디언트가 깔리므로 원판이 어두우면 뭉갠다.
**가장자리에 중요한 것을 두지 않는다** — 비율이 안 맞으면 잘라낸다.

# 자료(`type: 'screen'`)는 사진을 안 쓴다

헷갈리기 쉬운 지점이라 적어 둔다. 라운드 2 시안의 결론대로,
**감사인이 들여다보는 화면**(WMS 랙 점유 현황 · IAM 권한 대장)은 사진이 아니라
타이포와 격자로 세운다. 거기엔 사진이 들어갈 자리가 없다.

```
무대 · 초상   분위기   ← 사진(또는 영상)이 들어갈 자리
자료          데이터   ← 타이포와 격자. 사진 안 씀
```
