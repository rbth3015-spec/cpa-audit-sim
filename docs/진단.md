## 채점 방식에서 확인된 사실 (엔진 설계 근거)

- **"기준만 나열한 경우 일부 감점"** → 키워드 나열 방지 로직이 실제 채점과 일치
- **"예/아니오 판정이 틀려, 이유 서술의 정확성과 무관하게 부분점수를 부여하지 않았습니다"**
  → 판단 오답이면 근거 서술은 **0점** (부분점수 없음)
- **"기준서와의 정확도를 고려하여 점수를 차등 부여"** → 원문 정합성 채점
- 채점 코멘트가 곧 키워드 목록이다.
  예) "제한 사유가 '임원' 신분, 퇴직 후 1년 이내 기간요건, '공인회계사법' 근거 법령을 서술하였는지를 중심으로 채점"
