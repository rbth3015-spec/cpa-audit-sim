# Claude Design 에 보낼 요청서 — 감사 시즌 2026

아래 블록을 그대로 Claude Design 에 붙여넣으면 된다.
현재 구현은 `index.html`(토큰·컴포넌트) · `js/game.js`(화면) · `js/art.js`(사진 자리 대신 그리는 SVG) 에 있다.

---

## 붙여넣을 요청

```
「감사 시즌 2026」 웹 앱의 다음 단계다. 시안(Modernist)은 이미 코드로 옮겨졌고,
5개 화면(타이틀 · 플레이 · 판정 · 엔딩 · 연출)이 실제로 돌아간다.
지금 필요한 건 두 가지 — ① 사진 13장 ② 아직 시안이 없는 화면 6종.

## 지켜야 할 것 (이미 코드에 들어간 규칙)

- radius 0. 둥근 모서리는 엔딩의 감리 도장 하나뿐
- 구조 구분 2px 실선 / 내부 구분 1px. 여백으로 선을 대체하지 않는다
- 전부 flush left. 넓은 버튼은 라벨 왼쪽 · 보조 라벨 오른쪽
- 빨강 #ec3013 은 주 액션 · 위험 · 강조 한 단어에만
- 숫자는 전부 tabular-nums
- 토큰: --as-bg #f3f2f2 / --as-panel #ffffff / --as-panel-2 #eae9e9 / --as-sunk #e2e0df
  --as-ink #201e1d / --as-ink-2 #444141 / --as-dim #7d7979
  --as-line #d7d3d3 / --as-line-strong #201e1d / --as-rule #bab6b6
  --as-red #ec3013 / --as-red-soft #ffe0d9 / --as-warn #8a5a00 / --as-good #2f5d43
  (다크는 #131211 / #1a1918 / #221f1e / #0e0d0c … 기존 시안 그대로)

## ① 사진 13장

지금은 졸라맨 수준의 무채색 SVG 가 자리를 대신하고 있다. 이걸 진짜 사진으로 바꾼다.

### 전부에 공통

- **흑백만.** 색을 입히지 않는다. 코드에서 `filter: grayscale(1) contrast(1.1~1.16) brightness(.86~.95)` 가 한 번 더 걸린다
- **사진 안에 글자 · 로고 · 숫자 · 빨강을 넣지 마라.** 태그 · 마킹 · 도장은 전부 HTML 로 위에 올라간다
- 어두운 그라디언트가 위에 깔리므로 **원본은 중간~밝은 노출**로. 가장자리에는 중요한 디테일을 두지 마라
- 한국 사무실 · 공장의 실제 질감. 스톡 특유의 웃는 얼굴, 악수, 유리 빌딩 클리셰 금지
- 파일명 그대로 주면 바로 꽂는다 (`assets/art/` 에 들어간다)

### 무대 7장 — 16:7, 1600×700

플레이 화면 상단의 무대다. **하단 30% 는 대사 박스가 덮고**(모바일은 최대 55%),
좌상단에는 `SCENE 03 · 본사 창고` 같은 태그가 올라간다. 피사체는 상단 65% 안에 두고,
우측 상단에는 마킹(빨강 X 박스)이 올라갈 수 있으니 **실물**(재고 랙, 서류 더미, 모니터)을 배치해라.
오버레이: `radial-gradient(120% 90% at 30% 20%, transparent 30%, rgba(20,18,17,.72) 100%)`

### 인물 초상 5장 — 1:1, 512×512

대사 박스 왼쪽 136×136 칸에 들어가고, 좁은 화면에서는 가로로 눕는다.
**얼굴을 가로 정중앙, 위에서 35~45% 지점**에. 시선은 정면 또는 살짝 옆. 웃지 않는다.
배경은 단색에 가깝게(사무실 벽, 창고 벽). `filter: grayscale(1) contrast(1.12)`

## ② 아직 시안이 없는 화면 6종

시안(`감사 시즌 2026.dc.html`)에 없어서 내가 임의로 만든 것들이다. 제대로 잡아달라.
전부 위의 Modernist 규칙을 따른다.

1. **조서 서랍** — 우측에서 밀려 나오는 `min(400px, 94vw)` 드로어. 2px 좌측 보더, 그림자 없음.
   섹션: 회사의 태도(밴드 + 수치) / 발견한 사항(금액) / 확인 완료 / 진행 중 / 개념 카드 · 익힘 N /
   복습 카드 N / 기록(장면별 점수 + 이벤트). 지금은 섹션 라벨 + 1px 행으로만 되어 있다
2. **좌석 선택** — 타이틀 우측 컬럼 안. 어쏘 / 시니어 / 업무수행이사 3종.
   같은 시즌을 다른 자리로 다시 할 수 있다는 게 이 게임의 핵심인데 지금은 그냥 목록이다.
   선택 상태가 훨씬 분명해야 한다
3. **개념 카드 · 오답노트** — 제대로 짚은 논점은 익힌 카드, 놓친 논점은 복습 카드로 쌓인다(51장).
   지금은 1px 박스 + 좌측 2px 보더뿐. 카드가 익힘 ↔ 복습으로 넘어가는 상태 변화도 필요하다
4. **진행도 — 시즌 길이가 도중에 바뀐다** (새로 생긴 문제) — 한 시즌은 10~12 장면이고,
   조건이 맞으면 장면이 플레이 도중에 열린다. 예를 들어 특수관계자 장면에서 가공거래를
   찾아낸 순간 「부정 혐의 대응」이 열리면서 진행도가 `6 / 10` → `6 / 11` 로 늘어난다.
   지금은 HUD 의 16×8px 칩 줄이 말없이 한 칸 길어질 뿐이다. **장면이 하나 열렸다는 사실
   자체가 사건**이므로 그걸 알리는 방법이 필요하다 (칩 줄의 변화 · 전환 와이프에 얹는 표시 ·
   토스트 중 무엇이든). 반대로 "이번 시즌엔 이 장면이 없다"는 것은 드러내면 안 된다 —
   장면이 없다는 사실 자체가 스포일러다
5. **모바일 플레이 (≤560px)** — 지금은 데스크톱 레이아웃을 세로로 접기만 했다.
   HUD 게이지 4종, 무대 + 대사, 문항 + 답안 + 타이머가 한 손에 들어와야 한다
6. **자료 ② 메신저 캡처** — 시안에는 있었는데 우리 데이터에는 `memo` 타입만 있다.
   사내 메신저 캡처를 자료로 제시하는 컴포넌트(말풍선 3~4개 + 증거 태그)를 정식으로 만들어달라

## 납품

- 사진: PNG 또는 JPG, 위 파일명 그대로. 스톡이면 원본 URL + 촬영자 크레딧을 같이
- 화면: `.dc.html` 아트보드 하나에 6종을 모아서. 지금 코드의 클래스명(`as-dossier`, `as-seat`,
  `as-card`, `as-ask` …)을 그대로 쓰면 바로 옮긴다
```

| 무대 | `.as-stage__box` > `.as-art` | `16/7`, `min-height:300px` | 방사형 `.72` + `grayscale(1) contrast(1.1) brightness(.95)` |
| 타이틀 | `.as-title__art` > `.as-art` | 세로, `min-height:460px` (실제 1100~1400px) | 수직 `.10 → .88` + `grayscale(1) contrast(1.14) brightness(.92)` |
| 엔딩 | `.as-ending__hero` > `.as-art` | `21/8`, `min-height:280px` | 수직 `.34 → .80` + `grayscale(1) contrast(1.16) brightness(.86)` |
| 초상 | `.as-dialog__avatar` / `.as-ask__avatar` | `136×136` / `52×52` | `grayscale(1) contrast(1.12)` |

사진이 들어오면 `js/art.js` 의 SVG 를 `<img src="assets/art/...">` 로 바꾸기만 하면 된다.
필터와 그라디언트는 전부 CSS 에 있으므로 이미지 쪽은 손댈 게 없다.
